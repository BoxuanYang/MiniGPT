=====训练shakespear text的工作流=================

数据预处理, 生成train.bin和val.bin:
python data/shakespeare_char/prepare.py

训练模型:
CUDA_VISIBLE_DEVICES=7 python train.py config/train_shakespeare_char.py --compile=False --batch_size=32


产生样本:
python sample.py --out_dir=out-shakespeare-char

=====Task 1工作流=================

数据预处理: 生成train.bin和val.bin:
python data/rocmstories/prepare.py

数据预处理: 生成test_with_eot.txt:
python data/rocmstories/test_data_generation.py

训练模型:
CUDA_VISIBLE_DEVICES=1 python train.py config/train_rocmstories.py --compile=False --batch_size=32

评估模型:
python eval.py   \
 --init_from=resume   \
 --input_file=data/rocmstories/test.txt \
 --out_dir=out-rocmstories   \
 --device=cuda


产生样本:
python sample_batch.py --init_from=resume --out_dir=out-rocmstories --device=cpu

=============Task 2工作流=======================
数据预处理: 生成train_task2.bin和val_task2.bin:
python data/task2/prepare_task2.py

训练模型:

混合数据集训练:
python train.py config/train_task2.py --compile=False --batch_size=32

继续训练2000步:
python train.py config/train_rocmstories.py \
    --init_from='resume' \
    --out_dir='out-task2' \
    --dataset='rocmstories' \
    --learning_rate=1e-4 \
    --max_iters=17000 \
    --lr_decay_iters=17000 \
    --always_save_checkpoint=True \
    --compile=False \
    --batch_size=32

模型评估:
python eval.py   \
 --init_from=resume   \
 --input_file=data/rocmstories/test_with_eot.txt \
 --out_dir=out-task2   \
 --device=cuda

python eval.py   \
 --init_from=resume   \
 --input_file=data/rocmstories/test.txt \
 --out_dir=out-task2   \
 --device=cuda
